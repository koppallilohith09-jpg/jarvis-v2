# JARVIS V2 for Windows x64

Full friend distribution of application build **1.8.2**.

Download **jarvis-v2.zip** (1.39 GB), extract the entire ZIP, and run
`JARVIS-Local-Gestures.exe` inside `JARVIS-1.8.2-Friend`. Keep all support folders
beside the EXE. Windows native voice, Kokoro British voice and local Whisper
speech recognition are included.

This build includes visible-window launch confirmation, supported native
browser tab URL checks, managed-browser load checks, direct completion speech,
scoped cloud DNS fixes and camera timestamp/session fixes. It uses the original
JARVIS globe. Webcam eye tracking remains experimental.

Connect your own Gemini/OpenAI key for AI chat and document analysis. No offline
language model, personal keys, saved chats or creator profile is included.

166 source regression tests and the packaged application checks passed. ZIP
integrity was verified. Device/input adapters and cloud requests were simulated;
physical gesture accuracy and live AI generation were not verified by those
checks. SHA-256 hashes are listed in **SHA256SUMS.txt**.
